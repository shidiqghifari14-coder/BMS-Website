Sumber data BMS

UART5 STM: 115200 baud, 8N1. Gunakan USB–UART dan pilih port pada dialog browser.

Aktifkan hanya jika mapping interface A sesuai wiring Anda. Tanpa pilihan ini, data tegangan disimpan di CSV sebagai kanal lokal A, dan slot pack tetap kosong.

Perekaman menyimpan setiap sampel baru. Layar diperbarui terpisah. Log STM belum menyediakan timestamp akuisisi, SOC, atau umur data sensor.
